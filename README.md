## Selected work

### [Porto](https://github.com/Zghlul/Porto)

Personal portfolio, built as an application rather than a page. Every route renders through React inside Laravel, navigation runs through Inertia.js without full page reloads, and the visual system is three colors plus editorial typography. Nothing comes from a template or stock art. An automated WCAG 2 AA audit passes on the main, work, about, contact, and case-study routes.

`Laravel 12` · `Inertia.js v3` · `React 19` · `Vite 6` · `custom CSS`

### [SIPELAB](https://github.com/Zghlul/PeminjamanILKOM)

Laboratory borrowing system for the Communication Science programme at UNJ. Public lab schedules, room and equipment requests, a three-stage approval chain, handover and return records, queued mail, and a scheduler that keeps late and expired loans honest. The interface follows the programme's formal campus language rather than a SaaS landing-page style.

`Laravel 12` · `React 19` · `Inertia.js v2` · `Tailwind CSS v4`

### [iSafe](https://github.com/Zghlul/iSafe)

Stock administration for iPhone units tracked per IMEI: sales records, revenue and profit, stock reports, and export of transactions, reports, and stock lists to `.xlsx`.

`Laravel` · `MySQL` · `Blade` · `.xlsx export`

### [Petstay](https://github.com/Zghlul/Petstay)

Booking system for a pet boarding business: rooms, services, customers, bookings, and payments, with an admin area and public landing, services, and rooms pages.

`Laravel` · `Blade`
